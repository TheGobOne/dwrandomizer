## Learned rules
- Enable the reduce-flashing option for all future test runs of the emulator or ROM.
- Run all randomizer tests with default music enabled, not without music, since all players use default music.
- Do not prioritize mobile or phone layout for this project; desktop browsers are the only target.
- When outputting files, refer to the project as DWR instead of DWRando.
